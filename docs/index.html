Overview

Forge timestamps and wasm durations for scripts and CI receipts. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/forgewasm.git
cd forgewasm
node src/cli.js --help
node --test
